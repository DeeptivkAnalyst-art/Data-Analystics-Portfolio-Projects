# COVID-19-Global-Data-Analysis
COVID-19-Global-Data-Analysis-Project

# INTRODUCTION

This data analysis project explores global trends in daily new confirmed COVID-19 deaths and vaccination progress using publicly available datasets from Our World in Data. The project focuses on understanding how vaccination campaigns impacted COVID-19 death rates across different countries and time periods.
The analysis includes data cleaning, transformation, exploratory data analysis (EDA), and visualization techniques to uncover patterns, trends, and insights related to the pandemic.

### OBJECTIVES
* Analyze daily new confirmed COVID-19 deaths across countries.
* Examine vaccination progress over time.
* Compare vaccination rates with COVID-19 death trends.
* Identify countries with the highest and lowest vaccination coverage.
* Explore the relationship between vaccination rollout and reduction in deaths.
* Create interactive dashboards and visualizations for better understanding.

### DATASET INFORMATION

#### Source:

Dataset obtained from [Our World in Data.](https://ourworldindata.org/covid-deaths)

#### Dataset Features:
The dataset contains global COVID-19 statistics, including:
* `date` Date
* `location` Country/Location
* `new_case` Daily new confirmed deaths
* `total_cases`  Total covid cases
* `total_deaths` Total deaths
* `total_vaccinations` Total vaccinations
* `population` Population
* `continent`  Continent

# 1. DATA CLEANING PROCESS 

The dataset was cleaned using Excel.

Cleaning Steps include:
* Removed null and duplicate values
* Converted date columns into proper date format
* Filtered unnecessary columns
* Handled missing vaccination data
* Standardized country names
* Created calculated fields for: Death Percentage, Percent Population Infected & Rolling Case Counts. 

# 2. EXPLORATORY DATA ANALYSIS (EDA)

The Analysis included:

•	Country-wise trend analysis
