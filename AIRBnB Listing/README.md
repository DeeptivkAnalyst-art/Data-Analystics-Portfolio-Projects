# AirBnB-Listing-Anaysis
Airbnb Listing Data Analysis Project

## INTRODUCTION
This project focuses on analyzing Airbnb listing data using interactive data visualization techniques. The dashboard was created in Tableau to identify pricing trends, revenue patterns, and geographical insights from Airbnb listings. The analysis helps understand how property characteristics such as bedroom count and location impact pricing and revenue generation.

## OBJECTIVE

The main objectives of this project are:
* Analyze Airbnb listing prices across different bedroom categories 
* Identify high-performing zip codes based on pricing 
* Examine yearly revenue trends 
* Visualize geographical distribution of listing prices 
* Build an interactive dashboard for business insights.
  
## DATASET INFORMATION

Datasets Source: [AirBnB Listing](https://www.kaggle.com/datasets/alexanderfreberg/airbnb-listings-2016-dataset)

Dataset contains:
Listing ID , Zip code, Bedroom count, Price , Revenue, Calendar dates , Location.
The data was cleaned and transformed using Excel before visualization.

4. Price by Zipcode
5. Revenue for Year

#### Business Insights
* Larger properties generate higher average revenue and pricing.
* 1-bedroom listings have the highest supply in the market.
* Smaller properties dominate Airbnb listings, but larger properties generate significantly more revenue.

### CONCLUSION
In conclusion, this comprehensive analysis using Tableau provides valuable insights into the Seattle 2016 Airbnb market. By leveraging dynamic dashboards and various visualizations, we’ve explored key metrics such as average prices, revenue trends, and distribution patterns across different ZIP codes and bedroom configurations. The ability to interact with filters allows for a detailed examination of specific data points, enhancing our understanding of optimal rental strategies and market dynamics. This approach not only highlights significant trends but also supports informed decision-making for both hosts and potential renters.
